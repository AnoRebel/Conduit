## Release v3.2.1

### Changes since v3.2.0

- 32a110b fix(server): parse request URLs with the WHATWG URL API

### Installation

#### JSR
```bash
bunx jsr add @conduit/client@3.2.1
bunx jsr add @conduit/server@3.2.1
# or with npx
npx jsr add @conduit/client@3.2.1
npx jsr add @conduit/server@3.2.1
# or with deno
deno add jsr:@conduit/client@3.2.1
deno add jsr:@conduit/server@3.2.1
```

#### Go
```bash
go get github.com/AnoRebel/Conduit/packages/go-client@v3.2.1
```

### Docker

```bash
docker pull ghcr.io/anorebel/conduit/server:3.2.1
docker pull ghcr.io/anorebel/conduit/server-admin:3.2.1
docker pull ghcr.io/anorebel/conduit/admin-ui:3.2.1
```
